# CYANCAM

Windows screen recorder with system audio. Vietnamese interface.

Download the latest **CYANCAM-win-x64.zip** from [Releases](https://github.com/cyan881990/CYANCAM-releases/releases/latest), extract the ZIP to a writable folder, and open **CyanCam.exe**. Keep the bundled tools folder.

- Record a monitor, all monitors, a window, or a region selected by dragging.
- Capture speaker/headphone audio, choose the save folder, and save MP4 files with automatic names.
- F9 starts/stops recording. F10 stops and saves.
- A pulsing border shows what is being recorded. The indicator is excluded from the video on supported Windows versions.
- Automatic updates are configured in the app. The recording is saved before an update installs.

Windows 10 (2004 or newer) / Windows 11 x64. No separate .NET installation required.

This repository contains application downloads and release information. Application source code is maintained in a separate private repository. Recordings stay on your computer.

Third-party notices and FFmpeg license details are included in the download.
